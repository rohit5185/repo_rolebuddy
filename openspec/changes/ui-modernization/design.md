## Design System

(USE COLOR AND OTHER THEME AS IT IS WHAT WAS NOW)
(MAKE SURE UI DOESNT LOOK AI GENERATED, DO WEB SEARCH FOR IT, TO NOT LOOK UI GENERATED FROM AI ANYHOW) THIS IS VERY IMPORTANT, PROPER MODERN UI DESIGN, INDUSTRY READY TO LAUNCH AND SCALE.

### Layout
- Max width container: 1200px
- Consistent padding: 16px / 24px / 32px scale
- Use flex/grid only (no random positioning)

### Components
- Cards: rounded-xl, border, subtle shadow
- Buttons: consistent sizes (sm, md, lg)
- Inputs: full-width, consistent height

### Typography
- Clear hierarchy (heading, subheading, body)
- No random font sizes

### Colors
- Neutral-first palette
- Dark mode supported

### Responsiveness
- Mobile-first
- No horizontal overflow allowed

### UX Rules
- Dashboard shows:
  - role
  - partner
  - daily status (top priority)

  (MAKE SURE TO KEEP UI SAME ACROSS ALL PAGES)
