# Role Detail Pages — Design

# Overview

Role detail pages are ecosystem hubs for role-specific preparation communities.

These pages should feel:

* modern
* focused
* active
* trustworthy
* preparation-oriented

NOT social.

---

# Route Structure

Dynamic routes:

/roles/[slug]

Examples:

* /roles/nodejs-developer
* /roles/backend-developer
* /roles/data-analyst

Slug generation should remain clean and scalable.

---

# Page Layout

# HERO SECTION

Top section includes:

* role title
* ecosystem summary
* aspirant count
* active today count
* optional growth indicator

Primary CTA:
[ Find Preparation Partner ]

Secondary CTA optional:
[ Explore Similar Roles ]

---

# PREPARATION INSIGHTS SECTION

Display structured ecosystem insights.

Examples:

* most common goals
* preparation momentum
* active learning focus
* interview preparation trends

Presentation should remain:

* structured
* informational
* anonymous

---

# POPULAR SKILLS SECTION

Display:

* top skills
* technologies
* preparation tags

Example:
Express.js
MongoDB
REST APIs
Authentication
React
SQL

Use clean tag/chip design.

---

# COMMON DAILY GOALS SECTION

Examples:

* Solve 2 DSA questions
* Revise backend concepts
* Practice interviews
* Apply to companies

Goals should visually reinforce accountability culture.

---

# PREPARATION JOURNEY SECTION

Visual representation of common preparation phases.

Example stages:

1. Learning Fundamentals
2. Building Projects
3. Applying
4. Interview Preparation
5. Final Interviews

This section is ecosystem guidance only.

No progress tracking required in this phase.

---

# ACTIVE PREPARATION SIGNALS

Anonymous ecosystem activity indicators.

Examples:

* 14 people checked in today
* 6 users preparing for interviews
* 21 active learners this evening

Requirements:

* anonymous only
* no user identities
* no social posting behavior

This section should create:

* momentum
* ecosystem feeling
* preparation seriousness

---

# RELATED ROLES SECTION

Optional section:

* Backend Developer
* MERN Developer
* Full Stack Developer

Helps ecosystem navigation.

---

# UI Requirements

The page must feel:

* premium
* clean
* modern
* mobile-first
* trustworthy
* preparation-focused

Avoid:

* clutter
* feed appearance
* noisy visuals
* social-media patterns

---

# Mobile UX

Must prioritize mobile-first rendering:

* stacked sections
* responsive chips/tags
* readable typography
* proper spacing
* touch-friendly interactions

---

# Animation Requirements

Use subtle lightweight animations:

* section entrance transitions
* hover states
* CTA interactions
* loading skeletons

Animations must remain professional and non-distracting.

---

# Backend Requirements

Add aggregation support for:

* role statistics
* active counts
* top skills
* common goals
* anonymous preparation signals

No matching logic changes allowed.

---

# Scalability Requirements

Implementation must remain extensible for:

* peer interview mode
* ecosystem analytics
* role growth tracking
* preparation-stage intelligence
