# Professional Progress Foundation

## Why

RoleBuddy currently has only a basic streak system tied mainly to accountability matching. This does not properly represent overall preparation consistency across the platform and does not support the broader same-role peer preparation vision.

The current system:

* Feels incomplete
* Does not scale across connected peers
* Does not create professional trust indicators
* Does not reflect contribution quality

RoleBuddy is a professional peer preparation platform, not a gamified social application.

This change introduces a lightweight professional progress foundation focused on:

* consistency
* contribution
* reliability
* preparation readiness

without introducing heavy gamification systems like XP, coins, badges, or leaderboards.

---

## Goals

Introduce lightweight professional progress tracking that:

* works across the entire platform
* improves trust between peers
* improves discovery quality
* supports accountability behavior
* remains professional and minimal

---

## Scope

This change includes:

* Consistency tracking
* Contribution tracking
* Reliability calculation
* Preparation status calculation
* Backend schema updates
* Backend service logic
* API response updates
* Serializer updates

This change does NOT include:

* major frontend redesign
* leaderboard systems
* XP systems
* badges
* points
* notifications
* advanced analytics

Frontend UI integration will be handled in a separate OpenSpec change.

---

## Product Alignment

This system reinforces RoleBuddy’s core vision:

> Helping people preparing for the same role find reliable and active peers.

The system should:

* reward real participation
* improve peer trust
* improve connection quality
* stay invisible and professional

not:

* feel childish
* feel game-heavy
* distract from preparation workflows
